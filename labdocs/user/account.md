# 账号与权限

## 两种账号不要混淆

平台上有两类账号，用途完全不同：

| 账号类型 | 用途 | 登录方式 | 说明 |
|---|---|---|---|
| Linux 个人账号 | 登录 GPU 虚拟机，运行程序、管理自己的文件和环境。 | `ssh <user_id>@172.16.33.91` 或 `.247` | 每个人一个，家目录为 `/home/<user_id>`。 |
| OpenStack 项目账号 | 登录 Horizon 网页控制台，查看或管理项目内的实例、网络和卷。 | 浏览器访问 `http://172.16.23.41` | 项目级账号，例如 `<项目账号>`，不是 Linux 账号。 |

项目账号不能用来 SSH 登录虚拟机，Linux 账号也不能登录 Horizon。管理员账号只属于基础设施管理员，普通用户不应持有，也不应尝试使用。

一般地，个人用户通常不需要使用Openstack项目账号。

## 申请账号

新成员需要通过电子邮件提交账户开通申请。收件人和申请方式以实验室公布的内部通知为准，不在公开文档中列出个人邮箱。

- 邮件中必须写明：**姓名**、**学号或工号**、**研究用途**、**指导教师姓名**。
- 如果研究用途涉及 GPU，说明大概使用的框架、数据规模和预计使用时长，便于管理员分配资源。

不要借用他人账号，也不要帮他人代申请。账号与个人身份绑定，出现违规行为时按账号追溯。

## 登录服务器

服务器只允许在 N209C 局域网内访问。先连接实验室无线网 `ImmortalWrt-2.4G` 或 `ImmortalWrt-5G`，或者使用实验室有线网口，然后使用 SSH（Secure Shell，加密远程登录协议）登录：

```bash
ssh <user_id>@172.16.33.91
# 或
ssh <user_id>@172.16.33.247
```

第一次连接时，SSH 会提示确认服务器指纹。输入 `yes` 后继续。输入密码时屏幕不会显示字符，这是正常现象。

如果管理员提供的是初始密码，首次登录后立即修改：

```bash
passwd
```

也可以使用 SSH 公钥登录，避免每次输入密码。公钥放在服务器的 `~/.ssh/authorized_keys` 中，私钥只保存在自己的电脑上，不要上传到服务器、代码仓库或聊天工具。

推荐使用 VSCode 的 Remote-SSH 插件进行远程开发。它可以在本地编辑代码、在服务器上运行和调试，比纯命令行更方便。连接地址和普通 SSH 相同。

## 账号权限

普通用户在自己的家目录 `/home/<user_id>` 下有完整权限，可以创建文件、安装 Python 包、创建 Conda 环境。家目录之外的文件属于系统或其他用户，不要随意修改。

普通用户没有 `sudo` 权限。`sudo` 是 Linux 中临时获取管理员权限的命令；平台不向普通用户开放。以下操作都需要管理员完成：

- 安装或更新系统级软件、驱动、CUDA Toolkit。
- 修改 `/etc` 下的系统配置。
- 修改网络、防火墙、DNS 或代理设置。
- 挂载新的系统级磁盘或修改分区。
- 创建、删除其他用户账号。

如果需要某个系统级软件，先联系管理员说明用途，不要自己用 `apt` 安装。Python 包、R 包、Node.js 包这类用户级依赖可以装在自己的 Conda 环境或家目录中。

## 新成员准入

新成员第一次使用服务器前，由管理员进行简短的使用与安全说明，内容包括账号规则、GPU 使用、数据存放、网络限制和违规处理。用户确认已知晓这些规则后，再开通 GPU 权限或分配共享目录。具体规则见[使用规范](rules.md)。

## 账号安全

- 不要把账号借给他人，也不要用他人账号登录。
- 不要多人共用同一个 Linux 账号。需要多人协作时，每人申请自己的账号，通过共享目录或版本控制协作。
- 不要把密码写在脚本、Notebook、代码仓库或聊天记录里。
- 在公共电脑上登录后记得退出 SSH 会话。
- 发现账号异常、密码泄露或有人在用你的账号，立即修改密码并联系管理员。

## 账号生命周期

- **新成员**：按上面的流程申请，收到账号后先修改初始密码，再检查自己的家目录和 Conda 环境。
- **更换项目或导师**：账号通常保留，但资源归属和项目权限需要管理员调整。
- **离开实验室**：提前把需要保留的数据备份到自己的存储介质，通知管理员注销账号。账号注销后，家目录和其中的数据可能被清理。
- **长期不用**：如果账号长期不登录，管理员可能冻结或清理。重新使用前联系管理员恢复。

## 与账号有关的红线

以下行为属于账号与访问红线，一经发现可能被警告、强制终止进程、冻结账号、封禁账号或删除账号：

- 将个人账号借给他人使用。
- 使用他人账号登录服务器。
- 在非授权网络环境下尝试访问服务器。
- 恶意尝试破解、扫描或攻击服务器及局域网内其他设备。
- 尝试提权、绕过权限限制或访问未授权目录。

完整的违规处理规则见[使用规范](rules.md)。
